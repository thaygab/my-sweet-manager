# My Sweet Manager

Sistema de controle financeiro desenvolvido para gerenciamento de receitas e despesas.

## Tecnologias
- HTML5
- CSS3
- JavaScript
- LocalStorage

## Funcionalidades
- Cadastro de receitas
- Cadastro de despesas
- Cálculo automático de saldo
- Persistência de dados
